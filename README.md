# EduPiFlow

**Education Without Borders, Payments Without Friction**

EduPiFlow is an intelligent tuition fee management and payment platform built on Pi Network. It serves nursery, primary, secondary, and higher education institutions globally, with a primary pilot market in Rwanda.

## 💰 Payment Policy — IMPORTANT

**All payments within EduPiFlow are made exclusively in Pi Coin.**

The Rwandan Franc (RWF) and US Dollar (USD) are used **only as conversion and display tools** to help users understand the value of Pi in their local currency. No transaction is ever settled in RWF or USD.

- **Display** : RWF / USD equivalents shown for user convenience
- **Settlement** : 100% in Pi Coin on the Pi Network blockchain
- **Exchange rate** : BNR (National Bank of Rwanda) real-time rate, used for display only

## 🎯 Core Values

- **Trust** — Symmetric refundable security deposits + escrow protection
- **Flow** — Automated payments via Pi subscription smart contracts
- **Equity** — Simultaneous protection of parents and schools
- **Impact** — PiScholarship Engine funding education for underprivileged children

---

## 👥 Four Actors

| Actor | Role |
|---|---|
| **Parent/Guardian** | Pi authentication, family profile, child-school linking, tuition payments |
| **School/Institution** | Pi authentication, institutional profile, payment plans, report card publishing |
| **Student** | Receives non-transferable Academic SoulBound Tokens (SBTs) |
| **Pioneer Donor** | Creates anonymous or named scholarships, tracks impact |

---

## 🧩 Core Modules

1. **EduConnect** — Registration and profile linking

## 🛠 Tech Stack

- **Frontend** : React Native (iOS/Android) + React.js (school web dashboard)
- **Backend** : Node.js + Express
- **Database** : PostgreSQL + Redis
- **Blockchain** : Pi Network SDK (auth + payments), Pi token protocol (SBT), Pi subscription smart contracts
- **Offline** : Service Workers + IndexedDB (up to 50MB/user)

---

## 📊 Transaction Distribution

Every tuition payment processed through FlowPay is distributed as follows:

| Recipient | Share | Memo Code |
|---|---|---|
| School | 92% | — |
| Promoter (EduPiFlow) | 5% | EPF-COMMISSION |
| PiScholarship Fund | 2% | EPF-SCHOLAR-POOL |
| Reserve Fund | 1% | EPF-RESERVE |
